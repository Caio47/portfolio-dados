## Como rodar localmente

Pré-requisito: [Node.js](https://nodejs.org/) instalado.

```bash
# clonar o repositório
git clone https://github.com/Caio47/portfolio.git
cd portfolio

# instalar as dependências
npm install

# rodar em modo de desenvolvimento
npm run dev
```

O site abre em `http://localhost:5173`.

### Outros comandos

| Comando | O que faz |
|---|---|
| `npm run build` | Gera a versão de produção na pasta `dist` |
| `npm run preview` | Testa localmente a versão gerada |
| `npm run lint` | Analisa o código com o Oxlint |

## Estrutura

```
src/
├── components/   # um componente por seção (Header, Hero, Sobre, ...)
├── data/         # dados dos projetos (projeto.js)
├── App.jsx       # monta a página
├── App.css       # variáveis de cor, fontes e estilos globais
└── main.jsx      # ponto de entrada
```
